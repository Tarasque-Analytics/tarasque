# tarasque

tarasque is a full-stack web application for exploring volatility forecasts and ticker-level risk signals generated by the Tarasque model pipeline.

This repository contains both:
- App code (frontend + backend API) used by developers and users.
- Model code and research artifacts used by the quant workflow.

This README focuses on the app at a high level and describes how everything fits together.

## High-Level Model Overview

At a high level, the model estimates future realized volatility and compares it with market-implied volatility to surface potential dislocations.

Core ideas:
- Forecasting engine: ensemble of XGBoost, Random Forest, and LassoCV.
- Volatility baseline and stabilization: GARCH(1,1) overlay.
- Inputs: price/realized vol features, macro regime features, options-surface features, event features, and sector/factor context.
- Validation: walk-forward backtesting with RMSE, Mincer-Zarnowitz diagnostics, QLIKE, and event-capture analysis.

The model pipeline produces the volatility and options outputs that the app surfaces for visualization and analysis.

## App Architecture

The app is currently split into two local services:
- Frontend: React 19 + React Router 7 (SSR enabled), TypeScript, Vite, Tailwind CSS.
- Backend: FastAPI service that serves equity data to the frontend from a Supabase (Postgres) database.

Current data flow:
1. Backend queries Supabase (via `backend/database.py`) and aggregates per-equity data.
2. Frontend requests the ticker list and per-equity payloads from `http://localhost:8000/api`
   (`/api/equities`, `/api/equity/:symbol`).
3. UI renders charts and analysis views from backend responses.

## Quick Start (App Development)

Prerequisites:
- Node.js (project has been developed on Node 22.x)
- Python 3.8+

Install dependencies:

```bash
npm install
pip install -r backend/requirements.txt
```

Run both services (two terminals):

```bash
# Terminal 1 (backend)
python backend/main.py

# Terminal 2 (frontend)
npm run dev
```

URLs:
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:8000`
- API docs: `http://localhost:8000/docs`

## Build and Run (Production Style)

```bash
npm run build
npm run start
```

This builds and serves the SSR frontend bundle.

## Docker (Frontend)

```bash
docker build -t tarasque-app .
docker run -p 3000:3000 tarasque-app
```
